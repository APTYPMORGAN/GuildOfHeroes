## Собственный проект

Тема проекта: каталог игр

Главный класс: Game

Почему этот объект нужен программе: Потому что в нём будет храниться все данные о конкретных играх, чтобы каждый раз для отдельной игры не писать это всё заново и можно было легко задавать начальные данные

Какие данные хранит объект:
1. Название игры
2. Жанр игры
3. Год выхода игры
4. Рейтинг игры

Какие значения задаются через конструктор:
1. Название игры
2. Жанр игры
3. Год выхода игры

Какие значения можно задавать автоматически:
1. Рейтинг игры

Я решил задавать автоматически значение рейтинга, потому что изначально у каждой игры он равен нулю и формируется в дальнейшем, исходя из отзывов пользователей
